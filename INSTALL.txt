dsh-workbuddy-pool 1.0.0 — DeepSeek Harness 插件（Workbuddy 号池计量）
=====================================================================

两个产物，内容完全一样，任选其一：
  dsh-workbuddy-pool-1.0.0.zip   ← 双击解压即可，推荐给 Windows / 图形界面
  dsh-workbuddy-pool-1.0.0.tgz   ← npm 包格式，命令行装用这个

安装（图形界面）
----------------
1. 解压 zip，得到一个 dsh-workbuddy-pool/ 目录
2. 打开 DSH → 插件 → 添加插件 → 选中这个目录
3. 确认「Workbuddy 号池计量」已启用
4. 整页刷新（Cmd/Ctrl + R）——client 模块是新增的，热更新覆盖不到

安装（命令行）
--------------
  dsh plugin --profile <你的 profile> add /path/to/dsh-workbuddy-pool-1.0.0.tgz

配置（在 DSH 设置里改，推荐）
-----------------------------
装好后打开 设置 → Workbuddy 号池：
  - 面板地址：面板不在本机时填 http://你的面板地址:7863（留空则自动探测本机 7863）
  - 面板 API Key：粘贴面板 config.json 里的 api_key（只写不读，有「清除密钥」）
  - 三个间隔：轮询 / 今日用量 / 超时，秒为单位，保存即生效，不用重启
  - 测试连接：会明确告诉你是「不可达」还是「密钥被拒(401)」

设置存 $DSH_HOME/workbuddy-pool.json（0600），密钥单独存
$DSH_HOME/workbuddy-panel.key（0600），设置文件里不含秘密。

配置（命令行 / YAML 方式，可选）
--------------------------------
1) 面板地址：面板不在本机时，在你的 profile 的 cordis.patch.yml 里加

     - id: workbuddy-pool
       name: 'dsh-workbuddy-pool'
       config:
         baseUrl: 'http://你的面板地址:7863'

   留空则自动探测 http://127.0.0.1:7863 与 http://localhost:7863。

2) 面板密钥（面板 config.json 里的 api_key，等同管理员权限）：

     printf '%s\n' '<panel api_key>' > ~/.dsh/workbuddy-panel.key
     chmod 600 ~/.dsh/workbuddy-panel.key

   也可以改用环境变量 WORKBUDDY_PANEL_KEY。

面板端要求
----------
只读调用面板已有的 /panel/api/overview、/panel/api/request_metrics、
/panel/api/usage，不需要改面板。其中 active[]（在途账号/模型/实时 tok/s）
是 workbuddy2api 的一个补丁字段；面板没打补丁时插件仍可用，只是这几项退化为
「最近一次请求」的数据。

详细说明见 README.md 与 docs/DETAIL.md。
